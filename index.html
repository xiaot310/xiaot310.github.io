04 / Workbench

公开展示在云端，
研究工作留在本地。

这个站点有两层：GitHub Pages 上的公开主页，以及只在 127.0.0.1 运行的本地工作台。 工作台能列出最近文件、打开 LaTeX、画图、查文献、管理计划；这些私有内容不会上传。

  • 01计划、笔记、手绘默认存在浏览器 localStorage；可导出 JSON / PNG 备份。
  • 02文件列表由本地 Python 服务读取 D:\工作\研究生，只绑定本机，不暴露到公网。
  • 03LaTeX 私密链接放在 workbench/private.json，部署时被 .gitignore 排除。
